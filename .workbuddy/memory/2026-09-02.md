# 2026-09-02

## 启动 token-monitor（Electron 桌面端）
- 首次 `npm start` 失败：会话环境继承了 `ELECTRON_RUN_AS_NODE=1`，导致 Electron 二进制被当普通 Node 执行，`electron-updater` 报 `Cannot read properties of undefined (reading 'getVersion')`。解决：启动前 `unset ELECTRON_RUN_AS_NODE`。
- 第二次失败：WorkBuddy 终端沙箱内 GPU 子进程连续崩溃（exit_code=1），Chromium FATAL `GPU process isn't usable. Goodbye.`，渲染进程加载 ERR_FAILED(-2)。解决：加 Chromium 开关 `--disable-gpu --no-sandbox`。
- 最终可用启动命令（仅在本沙箱环境需要）：`unset ELECTRON_RUN_AS_NODE && ./node_modules/.bin/electron . --disable-gpu --no-sandbox`。用户在自己终端正常 `npm start` 即可，无需这些参数。
- 启动后采集器正常：监听 Codex / OpenCode / Trae / zcode / WorkBuddy / Qoder 等客户端目录并完成首轮采集。
